# DMA故障定位顺序

触发：传输超时、长度不一致、序号跳变、CRC失败、缓冲重复占用。

1. 保存出错前后MM2S/S2MM状态及参数，区分halting/idle/error，不以单一busy变量替代硬件状态。
2. 核对输入字宽、TLAST、传输字节、DMA长度位宽、实际输出容量和元数据。
3. 核对发送前flush、接收后invalidate；保持输入快照及返回bytes自有所有权，禁止下游仍使用时复用CMA视图。
4. 故障使整个会话失效；两个引擎都尝试复位，确认复位清除和安全状态后才释放活动缓冲。
5. 保留失败日志与部分输出；失败不产生成功报告；重新加载后用固定黄金样例确认恢复。
6. 计时时分开加载、搬运、计算、输出编码及端到端区间；区间重叠不得相加，不能把两个计时器差值直接归为纯DMA。

限制：寄存器定义依目标AXI DMA/VDMA和元数据核对；复位失败时不得强行释放仍可能活动的物理缓冲。适用依据为当前工程的故障注入与恢复证据，其他硬件需要独立验证。
