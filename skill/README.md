# 可复用工程技能

1. `checksum_audit.py`：对任意目录的SHA256清单做完整核验，不依赖本项目题目或板卡。用法：`python skill/checksum_audit.py <root> <manifest.json>`。本仓库manifest格式为files映射。失效条件：清单本身不可信、文件在校验后被修改；哈希不是真实性签名。此规则来自文件快照/缓存复用导致源结果混淆的检查经验。
2. `dma_failure_checklist.md`：基于AXI DMA状态、所有权和复位确认的排错清单。适用于有相同DMA生命周期的工程；具体寄存器和通道元数据必须核对，不承诺任意板卡直接适用。依据原模拟故障和板卡重载记录整理。
3. `prompt_workflow.md`：算法划分、计时边界、可复现性的提示词模板。它是本轮整理的模板，需由使用者再次验证效果，不宣称已经验证所有新题目。

评价边界：通用核验脚本可跨目录直接使用；PYNQ特定清单仅在当前板卡/设计的已记录故障场景中验证，未虚报跨板物理验证或额外加分资格。
