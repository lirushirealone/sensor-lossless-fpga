# UCF1 / UHC1

固定64字节文件头，小端`<4sBBH4Q6I>`：magic UCF1、版本1、flags0、头长64、四通道样本数u64、格式1、最大任务8192、原生子块1024、批大小1/2、reserved0、前60字节CRC32。

随后为独立24字节UHC1帧，小端`<4sBBBBIHHII>`：magic、版本、通道、mode、参数、实际输出序号、点数、正文长度、原值CRC32、前20字节元数据CRC32。mode0为原始int16，mode1/2为previous/trend Rice，mode3/4为previous/trend四点分组，mode5为可逆modulo16差分后的zlib。原生帧最大1024点，raw/DEFLATE最大8192点。

每帧独立预测/字典；校验总样本数以检测整帧尾部丢失。拒绝未知模式、保留位、重复跳号、截断、超量解压、CRC与计数不一致。原始样本以16位有效字节统计，压缩体积包含64字节文件头和所有24字节帧头。空间节省=1-完整文件字节/有效采样字节；不得平均各通道百分比代替字节加权总比例。
