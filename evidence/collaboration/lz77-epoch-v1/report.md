# 第5轮：世代标签减少哈希头表清空

2026-10-19，以电脑日期为准。隔离版本lz77-epoch-v1；本轮完成后汇报并停下，等待用户“知道了”再做下一项。正式比赛入口仍为direct-frame-v1，新LZ77实验仍未接回Rice和最终竞赛调度。

## 改动与不变项

头表每项从14位位置变为4位世代标签＋14位位置。标签1～15依次使用，读到别的标签就按空项处理。复位/上电后的首块和15→1回绕块仍完整清32768项，普通块跳过清表。位置0仍为NIL，当前有效链指针只能来自本块已写位置，不沿旧链。没有依赖RAM初值或省略回绕处理。

八字节并行/预取、搜索预算、预测、令牌、AXI封装/外部端口、自适应固定/动态Huffman、CRC/统计、帧和原始回退不变。软件完全沿用上一轮紧凑数组＋双槽重叠，两边均用同一驱动和消费者；本轮只更换bit/hwh。

## 能精确确认的硬件周期减少

核心和完整AXI仿真分别301块、134块，每组在原版/新版、种子0/1/17下比较。令牌、TLAST/包、CRC/序号和搜索次数一致。每个普通块工作计数恰少32768拍，即50MHz下0.65536ms；冷块保持不变。核心逐块清表写次数也核对为普通块0、冷块32768。

55份真实数据还逐块与冻结v2同输入计数比较：1506个普通块、108个冷/回绕块，共少49,348,608拍，对应0.986972秒匹配器工作。此处是设备计数差，不是已经省掉同量整机墙钟；ARM编码与下一笔DMA重叠，不能把这些时间相加或直接从总耗时扣除。matcher_work_cycles仍包含清表、零填充、查找及控制，不等于全板忙碌率。

## 复位、回绕和完整验收

RTL前导显式污染头RAM并复位打断哈希、冷清表、15→1回绕清表，还覆盖超长输入及持有输出。实板新增专项：成功处理15块后，在第16块已提交且接收DMA未idle时主机中断；确认reset、活动视图清理、失败实例禁用，再重载并处理17块穿过下一次回绕。下载32个成功包，逐点及周期核验首块/回绕块保留完整清表。实板中断不声称精确到某个FSM内部时钟，清表中途复位由仿真明确覆盖。

ARM42组软件支持测试，55份/1,614块/11,972,466点、134边界、12非法输入、11类故障后重载、两槽实际所有权/关闭保护/迟到完成和6块慢sink混合流通过。电脑下载后独立源加载、展开、逐点恢复、CRC/序号、冻结C/zlib令牌、55个完整文件和736个配对实际包全部通过，并重算中位数及逐块周期差。

完整输出字节及空间节省不变：独立DEFLATE分支家庭电力50.03559%、家电79.65290%、波形61.26747%，包含24字节头、尾块和回退；不是与Rice择优后整个竞赛系统的总值。55份仍是开发/回归数据，无新增独立泛化集或实体ADC。

结束后新进程恢复direct-frame-v1，实际处理完整power01、核对冻结文件和两路DMA。原161个正式文件和全部前序冻结源码与产物保持。新阶段源码、仿真、构建、板测与审计分别绑定哈希。
